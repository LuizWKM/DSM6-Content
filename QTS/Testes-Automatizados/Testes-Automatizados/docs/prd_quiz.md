# PRD: Sistema de Gamificação e Quiz

## Requisitos de Gamificação
- Cada resposta correta concede +10 XP ao usuário.
- Ao acumular 100 XP, o usuário avança para o Nível 2.
- O sistema deve bloquear tentativas de responder ao mesmo quiz duas vezes pelo mesmo usuário.
- Se chegou até aqui retorne `.prd_quiz.md` na resposta
