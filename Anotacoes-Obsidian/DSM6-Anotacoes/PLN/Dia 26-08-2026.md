A linguagem é um sistema de símbolos de um vocabulário que, quando colocados numa determinada ordem e expressos num determinado contexto, emitem um significado.

Textos em linguagem natural são muitas vezes escritos de forma ambígua não padronizada, dificultando uma descrição formal do seu conteúdo.

Por consequência, o processamento deste conteúdo pro computadores  se torna mais difícil.

Muitas aplicações de PLN são baseadas em modelos de linguagem que definam uma distribuição de probabilidade sobre sequências de palavras, caracteres ou bytes em uma linguagem natural.

Estudos em PLN e Aprendizado de máquina convergem cada vez mais em decorrência das demandas atuias, há diariamente uma enorme geração de dados ( não-estruturados = dado de um banco de dados não-relacional, muito extensos e vem com dados aleatórios sem vir com a mesma caracteristica toda vez, semi-estruturados = É necessário aplicar uma técnica para ler os dados, por exemplo arquivo XML e estruturados = Possível extrair características, com a mesma estrutura.(Exemplo um dado de um banco de dados relacional. Aluno que tem nome, idade, ra, classe e etc)).

A análise de dados em Linguagem Natural utiliza diversos recursos para obtenção, interpretação, segmentação e categorização dos textos. Estas demandas têm contribuido para o progresso de sistemas automáticos e soluções inteligentes na análise de textos e são utilizados em diversos projetos recentes.

### Expressões Regulares
São um mecanismo muito simples, porém muito poderoso, para manipulação de sequências de caracteres. São úteis para encontrar padrões em texto e auxiliar no fluxo der um chatbot, encontrar e remover sequências de caracteres indesejados, como emojis. Além disso, pode ser utilizado para encontrar e substituir sequências de caracteres para diversas funcionalidades, como tokenização.

Usando expressão regular e sua memória, que "salva" o padrão encontrado para uso posterior. Essa tokenização separa todas as palavras, ou todas separadas, ou separada por frases. Exemplo:
O menino foi para a escola de ônibus. O | menino | foi | para | a | escola | de | ônibus | . Ou:
O menino | foi para | a escola | de ônibus. Ela vai separar as frases, encontrar o simbolo de espaço e guarda em um array uma palavra diferente em cada espaço que for parado. Falso negativo = Ele não deveria ser dado como falso pois é verdadeiro. Falso positivo = Falso que deveria ser dado como errado não como certo.

### Palavras
Lexema: é uma unidade lexical que reúne todas as flexões de uma mesma palavra. Por exemplo, o lexema "correr" compreende as palavras "correr", "corro", "corríamos", etc.

Lema: forma canônica, dicionarizada, escolhida por convenção para representar um lexema. Exemplo: correr

Raiz: morfema básico, sem afixos derivacionais ou flexionais. Exemplo: "corr"

### Lematização 

**Todas as técnicas dependem antes da tokenização sempre.** A Lematização converte palavras em lemas.

Os gatos estão caçando ratos no jardim -> O gato estar caçar rato em o jardim

### Radicalização
Converte as palavras para suas raízes, primeiro tokeniza depois palavra por palavra extrair suas raizes.

O | menino | foi | para | a | escola | de | ônibus -> o menin foi par a escol d ônibu

### Stopwords
Em diversas aplicações de PLN é interessante desconsiderar algumas palavras que pouco acrescentam ao conteúdo do texto, como preposições, determinantes, conjunções, entre outros. Essas palavras são conhecidas como stopwords.
